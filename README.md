
# 🎙️ Resonator - Podcast Landing Page

A modern, pixel-perfect, and fully responsive podcast landing page converted from a Figma design. Built with clean code, smooth interactions, and a custom functional audio player.

## ✨ Features

- **Pixel-Perfect Figma Conversion:** Meticulously crafted to match the original design layout.
- **Custom Audio Player:** Fully functional HTML5 audio player featuring play/pause controls, dynamic progress bar with scrubbing/knob, playback speed toggles (10x / 15x), volume mute/unmute, and live time tracking.
- **100% Responsive Design:** Optimized for mobile phones, tablets, and desktop viewports with a functional mobile menu toggle.
- **Interactive UI Elements:** Smooth scrolling navigation, hover micro-interactions, and card layouts.
- **FontAwesome Integration:** Clean vector icons for enhanced user experience across all devices.

## 🛠️ Tech Stack

- **HTML5** (Semantic markup)
- **Tailwind CSS** (Utility-first styling)
- **Vanilla JavaScript (ES6+)** (DOM manipulation and custom audio player logic)
- **FontAwesome** (Icons)
